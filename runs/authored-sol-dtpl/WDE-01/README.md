# Ridgeline marketing site

A responsive, dependency-free single-page concept for a restaurant payroll and scheduling product. Open `index.html` directly or serve the directory with any static server.

## Material assumptions
- Ridgeline is treated as a new/concept brand; no existing brand system, product screenshots, pricing, testimonials, certifications, or verified performance claims were supplied.
- The primary conversion is a walkthrough request, represented by a mail link to the reserved `.example` domain rather than a non-functional lead form.
- Product UI, employee names, restaurant name, dates, totals, and calculator results are explicitly illustrative.
- Core product scope is schedule creation, hourly time tracking, timecard approval, and payroll review. Unsupported integration/compliance claims were intentionally avoided.
- The visual direction uses an independent-restaurant palette and a recurring ticket/ledger motif. Google Fonts enhance the design; system fallbacks preserve usability offline.

## Files
- `index.html` — semantic page content
- `styles.css` — responsive visual system
- `script.js` — mobile menu, calculator, and demo state
