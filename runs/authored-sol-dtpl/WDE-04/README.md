# Rhythm prototype

A clickable mobile React prototype with a Today view, interactive habit completion, streak detail, and add-habit sheet.

## Run

```bash
npm install
npm run dev
```

## Material assumptions

- The prototype is mobile-first and shown in a phone-width frame on larger screens.
- Habit state is session-only; no account, persistence, or backend is implied.
- The streak calendar uses illustrative May data, while newly added habits appear immediately in Today.
- “Journey” opens the requested streak detail; Insights and profile are intentionally inert because they are outside the requested prototype scope.
