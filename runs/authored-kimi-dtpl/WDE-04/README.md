# Tending — mobile habit prototype

## Run
`npm install && npm run dev`

## Material assumptions
- This is a local, single-user prototype; changes last only for the current browser session.
- The primary daily task is checking off today’s habits. Streak history is illustrative.
- Monday is the first day of the week, and new habits default to every day.
- The layout is mobile-first and presented in a device-width canvas on larger screens.
