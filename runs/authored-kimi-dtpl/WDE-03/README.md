# Northstar pricing page

A polished, responsive pricing-page concept for an illustrative B2B analytics product. Open `index.html` directly or serve this directory with any static server.

## Material assumptions

- Northstar is a fictional product; pricing, limits, uptime target, and product capabilities are illustrative rather than factual claims.
- The primary conversion is a 14-day trial; enterprise buyers are routed to sales.
- Annual prices represent approximately 20% savings and are shown as monthly equivalents billed annually.
- Trial buttons intentionally show local prototype feedback and do not submit data or create accounts.
- DM Sans and Manrope are loaded from Google Fonts with metrically reasonable system fallbacks; the page remains usable if remote fonts fail.

## Verification

Run `./verify.sh` to check local links, JavaScript syntax, HTML structure, and wide/narrow Chromium renders. Screenshots are written to `artifacts/`.
