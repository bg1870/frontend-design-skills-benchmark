# Material assumptions

- **Product:** Sundial is a new, independent day-planning web application. The name, positioning, voice, and visual identity are original directions created for this landing page.
- **Launch timing:** “Next month” is interpreted from the current runtime date as October 2026. Update this copy if the launch window changes.
- **Claims:** No customer, adoption, pricing, performance, or compatibility claims are made because none were supplied.
- **Signup infrastructure:** The included form provides complete client-side validation and confirmation for the prototype, but it does not persist or transmit addresses. Connect the submit handler in `script.js` to the chosen email platform before publishing, and replace the success state only after a confirmed response.
- **Deployment:** The artifact is framework-free static HTML/CSS/JavaScript and assumes deployment from the site root over HTTPS.
