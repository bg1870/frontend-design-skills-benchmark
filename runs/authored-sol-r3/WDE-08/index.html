Claude response.

Nojom is our typed, lightweight wrapper around the Claude API. Add the package, set one environment variable, and make your first request.

Start building ↓
01

INSTALL

Add the SDK

Install Nojom with your project’s package manager. TypeScript types are included.

Terminal
$ npm install @nojom/sdk
02

AUTHENTICATE

Set your API key

Store the key in your environment. The client reads it automatically—never commit it to source control.

i

Get an API key from the internal developer portal, then add it to .env.local.

.env.local
NOJOM_API_KEY=your_api_key_here
03

FIRST REQUEST

Send a message

Create a client and pass a prompt. The response is fully typed, including content blocks and usage.

index.ts
import { Nojom } from "@nojom/sdk";

const nojom = new Nojom();

const response = await nojom.messages.create({
  model: "claude-sonnet-4-20250514",
  maxTokens: 1024,
  messages: [
    { role: "user", content: "Explain what this code does." }
  ]
});

console.log(response.content[0].text);

Current default: claude-sonnet-4-20250514

04

ESTIMATE COST

Know the cost before you ship

Claude Sonnet 4 usage is metered separately for input and output tokens.

INPUT$3per 1M tokens
OUTPUT$15per 1M tokens
(input tokens × $3 + output tokens × $15) ÷ 1,000,000

Example: A request using 2,000 input tokens and 500 output tokens costs approximately $0.0135.

Standard API rates shown. Prompt caching, batch processing, and future pricing changes can affect actual spend.
