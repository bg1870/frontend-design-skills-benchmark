# Material assumptions

- This is a frontend-only clickable prototype; habit state is held in memory and resets on refresh.
- All habits, completion history, and streak values are illustrative sample data, labeled in the interface.
- The Today date and greeting derive from the viewer’s local runtime clock and timezone.
- The primary viewport is mobile (360–430px), with a composed desktop presentation rather than a separate desktop product experience.
- No brand assets or visual system were supplied, so the name **Tend** and the warm botanical visual direction are prototype choices.
