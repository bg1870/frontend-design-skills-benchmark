# Clearframe pricing page

A responsive, accessible static pricing page for a fictional B2B product analytics platform. Open `index.html` directly or serve the folder over HTTP.

## Material assumptions

- Clearframe is a fictional mid-market product analytics company; brand, customer, metrics, plans, and prices are illustrative.
- Annual prices are monthly equivalents billed annually and represent roughly 20% savings.
- The primary conversion is a Scale trial; Enterprise routes to a sales conversation.
- Google Fonts enhances the design when online; purposeful system fallbacks preserve usability offline.
- The placeholder `.example` sales address intentionally does not route to a real company.

## Run

```sh
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
