TS TYPESCRIPT SDK

Build with Nojom

Make your first Claude request in under five minutes. Nojom gives your TypeScript app a small, typed interface to the Claude API.

Before you beginNode.js 18 or later·A Nojom API key
1

Install the SDK

Add Nojom to your project using your preferred package manager.

$ npm install @nojom/sdk
2

Set your API key

Create a key in the Nojom console ↗, then expose it as an environment variable.

◇
Keep your key private

Never commit API keys or expose them in browser code. Make requests from a trusted server.

.env
NOJOM_API_KEY=nj_live_your_key_here
3

Send your first request

Create a message and print Claude’s response.

index.ts
import { Nojom } from "@nojom/sdk";

const nojom = new Nojom({
  apiKey: process.env.NOJOM_API_KEY,
});

const message = await nojom.messages.create({
  model: "claude-sonnet-4-5-20250929",
  maxTokens: 1024,
  messages: [
    { role: "user", content: "Explain quantum computing in one sentence." },
  ],
});

console.log(message.content[0].text);
Run it withnpx tsx index.ts
