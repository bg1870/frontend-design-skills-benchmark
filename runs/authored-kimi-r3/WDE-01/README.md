# Ridgeline marketing site

A responsive, single-page static marketing site for an independent-restaurant payroll and scheduling product.

## Run

Open `index.html` directly, or serve the directory with any static server (for example `python3 -m http.server 8000`).

## Material assumptions

- Ridgeline is an early-stage US-focused SaaS brand with scheduling, time tracking, and full-service payroll.
- The primary conversion is booking a product demo; pricing is therefore sales-assisted rather than shown as fixed tiers.
- Brand identity, customer names, metrics, and testimonial are illustrative marketing content.
- The site uses Google Fonts and one Unsplash restaurant image, with graceful local font/color fallbacks if external assets are unavailable.
- This artifact is front-end only; login, demo booking, and legal destinations are placeholders pending real routes/backend integration.
