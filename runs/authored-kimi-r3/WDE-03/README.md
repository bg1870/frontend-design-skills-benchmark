# Siftly Pricing Page

A responsive, accessible static pricing page for a fictional B2B analytics platform.

## Run

Open `index.html` directly, or serve the directory:

```bash
python3 -m http.server 8000
```

## Material assumptions

- Siftly is a fictional product and the brand, plan names, prices, customer marks, and copy are original placeholders.
- Annual pricing is shown as a monthly equivalent and billed annually; monthly pricing is $499.
- The primary conversion paths are self-serve trial and enterprise sales contact.
- This deliverable intentionally has no framework/build dependency and works as static files.
