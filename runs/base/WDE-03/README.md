# Northstar pricing page

A responsive, dependency-light pricing page for a fictional B2B analytics product.

## Run

Open `index.html` directly or run:

```bash
python3 -m http.server 8000
```

## Material assumptions

- Northstar is a fictional modern analytics SaaS aimed at small teams through enterprises.
- Pricing is positioned at $49/user monthly or $39/user/month billed annually; Starter is free and Scale is custom.
- Primary conversion goals are a Growth trial and enterprise demo.
- Brand assets and customer names are illustrative placeholders, not real endorsements.
- Google Fonts enhance the design when online; system fallbacks keep the page usable offline.
