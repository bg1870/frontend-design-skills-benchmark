# Ritual — clickable habit tracker prototype

A polished mobile-first React prototype with a Today view, interactive completion states, streak details, and an add-habit sheet.

## Run

```bash
npm install
npm run dev
```

## Assumptions

- This is a local prototype; data persists only for the active browser session.
- Monday is the first day of the week.
- Completing a habit updates today's progress and its streak preview optimistically.
- The bottom navigation's secondary tabs are lightweight prototype states; the primary requested flows are fully interactive.
