# Ridgeline marketing site

A responsive, single-page marketing site for an independent-restaurant payroll and scheduling product.

## Run

Open `index.html` directly, or serve the directory with any static server, for example:

```bash
python3 -m http.server 8080
```

## Material assumptions

- Ridgeline is positioned as a warm, approachable US-focused SaaS product for independent restaurant owners.
- The primary conversion is booking a free demo; pricing is intentionally not invented.
- Product metrics, testimonials, restaurant names, and people are representative marketing copy for the concept and should be replaced with verified customer claims before publication.
- Google Fonts and Unsplash imagery are loaded remotely; production use should confirm licensing and self-host optimized assets where appropriate.
