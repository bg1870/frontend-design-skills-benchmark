# Astra pricing page

A responsive, dependency-free pricing page for a fictional B2B product analytics company.

## Run

Open `index.html` directly, or serve the folder with any static server (for example `python3 -m http.server 8000`).

## Material assumptions

- Astra is a fictional product; plan names, prices, allowances, and policies are illustrative product copy rather than claims about a real company.
- Annual billing displays a 20% discount rounded to whole dollars.
- The trial form is intentionally a local demo and says so after submission; no data is transmitted.
- Google Fonts enhance the typography when online. System fallbacks preserve the layout offline.
