## `fixtures/site/index.html`

### Critical

`fixtures/site/index.html:43-61` — **Critical:** navigation is implemented with `onclick` on non-interactive `<li>` elements. The rows cannot be focused or activated by keyboard and do not support Cmd/Ctrl-click. Rules: use `<a>` for navigation; never use `<div>/<span>`-style click handlers in place of semantic controls; interactive elements require keyboard access.

`fixtures/site/index.html:45,49,53,57,61` — **Critical:** all integration icon-only buttons lack accessible names. Rule: icon-only buttons require `aria-label`.

`fixtures/site/index.html:70` — **Critical:** the email field has no `<label>` or `aria-label`. Placeholder text is not a label. Rule: every form control requires an accessible, clickable label.

### High

`fixtures/site/index.html:70` — **High:** email uses `type="text"` rather than `type="email"`. Rule: use the correct input type and input mode so browsers can validate and show an appropriate keyboard.

`fixtures/site/index.html:70` — **High:** missing `autocomplete="email"` and `spellcheck="false"`. Rules: inputs need meaningful autocomplete; disable spellcheck for email addresses.

`fixtures/site/index.html:19` — **High:** header menu button has no `aria-label`; its SVG is not hidden from assistive technology. It also has no scripted behavior, so it appears to be an inoperative control.

`fixtures/site/index.html:17,26` — **High:** duplicate `id="cta"` values violate HTML ID uniqueness and make DOM targeting ambiguous. Use a unique ID or remove these IDs.

`fixtures/site/index.html:12-22` — **High:** no skip link before repeated navigation. Guideline: include a keyboard-accessible “Skip to main content” link and a matching main-content target.

`fixtures/site/index.html:43-61` — **High:** each row contains a button inside a separately clickable parent. This creates conflicting interaction targets: mouse activation on either navigates, while keyboard activation on the button does nothing. One semantic link should own the complete row.

### Medium

`fixtures/site/index.html:44,48,52,56,60` — **Medium:** integration images lack explicit HTML `width` and `height`. CSS dimensions do not satisfy the guideline requiring image attributes to reserve aspect-ratio space and prevent layout shift.

`fixtures/site/index.html:45,49,53,57,61` — **Medium:** decorative chevron SVGs lack `aria-hidden="true"`. Rule: decorative icons should be hidden from assistive technology.

`fixtures/site/index.html:19` — **Medium:** hamburger SVG also lacks `aria-hidden="true"` once the button itself receives an accessible name.

`fixtures/site/index.html:70` — **Medium:** placeholder should show an example pattern and end in an ellipsis, such as `name@clinic.com…`, under the form-placeholder guideline.

`fixtures/site/index.html:7-8` — **Medium:** Google Fonts ultimately serves font files from `fonts.gstatic.com`, but only `fonts.googleapis.com` is preconnected. Performance rule: preconnect to asset/CDN origins; add the `fonts.gstatic.com` cross-origin preconnect or reduce external font usage.

`fixtures/site/index.html:80-85` — **Medium:** animation setup assumes `IntersectionObserver` exists and offers no fallback. Failure leaves `.reveal` content permanently hidden because of `styles.css:92`.

`fixtures/site/index.html:31,34,67,71` — **Low:** “How it works,” “Start free,” and “Create workspace” use sentence case, while the supplied interface guideline requires Chicago-style Title Case for headings and buttons.
