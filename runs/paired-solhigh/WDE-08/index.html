01

Install the SDK

Add Nojom with your project’s package manager.

Terminal
npm install @nojom/sdk
02

Set your API key

Keep the key on the server. Nojom reads it from the environment by default.

.env
NOJOM_API_KEY=your_api_key_here
Do not prefix this variable with NEXT_PUBLIC_ or expose it in browser code.
03

Send your first request

Create a client and ask the current Sonnet model for a concise response.

src/hello.ts
import { Nojom } from "@nojom/sdk";

const nojom = new Nojom();

const message = await nojom.messages.create({
  model: "claude-sonnet-4-20250514",
  maxTokens: 256,
  messages: [
    { role: "user", content: "Explain event loops in one sentence." },
  ],
});

console.log(message.content[0].text);
Run with npx tsx src/hello.ts. The response also includes usage counts for input and output tokens.
