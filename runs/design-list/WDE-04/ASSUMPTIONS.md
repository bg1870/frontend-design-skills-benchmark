# Material assumptions

- Audience: an individual building calm, sustainable daily routines.
- Product posture: warm and encouraging rather than competitive or gamified.
- Primary device: 390 by 844 point mobile viewport, with a desktop presentation frame.
- Key paths: complete a habit, inspect a streak, return to today, and add a named daily habit.
- Data is local prototype data and resets on refresh. No account, persistence, notifications, or backend is implied.
- The September date and activity are illustrative interface content, not performance claims.
