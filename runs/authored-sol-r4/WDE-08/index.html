01INSTALL

Add Nojom to your project

Use your project’s package manager. Node.js 18 or later is assumed.

TERMINAL
$ npm install @nojom/sdk
02AUTHENTICATE

Keep the key server-side

Store your Anthropic API key as an environment variable. Never expose it in browser code or commit it to source control.

.ENV
ANTHROPIC_API_KEY=your_api_key_here
03FIRST REQUEST

Send your first message

Nojom reads the key from your environment and returns a typed Claude response.

CURRENT MODEL · SONNET 5
index.ts
import { Nojom } from "@nojom/sdk";

const nojom = new Nojom();

const response = await nojom.messages.create({
  model: "claude-sonnet-5",
  maxTokens: 1024,
  messages: [
    { role: "user", content: "Explain type narrowing in one sentence." }
  ]
});

console.log(response.content[0].text);
