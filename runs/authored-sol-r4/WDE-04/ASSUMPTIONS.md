# Material assumptions

- This is a front-end prototype with illustrative habit and streak records, not persisted user data. The interface labels the data as “Sample data.”
- The reference date is the runtime date, September 9, 2026, interpreted in EEST (UTC+03:00). The prototype uses an English locale.
- Habit additions and completion changes live only in React memory and reset on reload.
- “Tempo” is a fictional prototype name and is not intended to represent an existing organization or trademark claim.
- The prototype is mobile-first; on wider screens it is presented in a handset frame with an explanatory display panel.
