# Northstar pricing page

A responsive, dependency-free pricing page for a fictional B2B analytics product.

## Run

Open `index.html` directly, or serve the folder with:

```bash
python3 -m http.server 8080
```

## Material assumptions

- No existing brand, codebase, assets, or product facts were supplied, so the Northstar identity and plan structure are representative.
- Prices are illustrative USD pricing and are labelled without unsupported customer or performance claims.
- Primary conversion uses pre-addressed email links so every visible CTA has a functional destination in a static artifact.
- Google Fonts enhance the typography when online; local system fallbacks preserve the layout offline.
