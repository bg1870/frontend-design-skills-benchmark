# Material assumptions

- The prototype targets a 390×844 mobile viewport and remains usable on desktop in a device-width shell.
- “Today” is Tuesday, September 8; sample activity is local-only and resets on reload.
- Completing a habit is immediate; adding one requires a name and creates it in today’s list.
- Streak detail is opened from the featured reading habit; bottom navigation returns to Today.
- The visual metaphor is a printed daily punch card: ruled rows, condensed display type, and a moving completion rail.
