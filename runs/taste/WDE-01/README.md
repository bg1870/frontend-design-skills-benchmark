# Ridgeline marketing site

A responsive single-page marketing site for a restaurant scheduling and payroll SaaS.

## Run

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Material assumptions

- Ridgeline is a new brand with no supplied identity, assets, legal copy, testimonials, customer list, or verified product metrics.
- Pricing, customer names, testimonial, contact address, and interface data are illustrative and should be replaced before production.
- The primary conversion is a 14-day free trial with no credit card.
- The target customer is a US-based independent restaurant with one location and 10-50 employees.
- Photography is externally hosted Unsplash imagery and requires network access. Confirm licensing and replace with owned brand photography before launch.
- The page respects the visitor's system light/dark preference and reduced-motion setting.
- No build step or package installation is required.
