# Metrik pricing page

A standalone, responsive pricing page for a fictional B2B revenue analytics product.

## Run

Open `index.html` directly, or serve the directory:

```bash
python3 -m http.server 8000
```

## Material assumptions

- Metrik sells to revenue operations teams at mid-market and enterprise B2B companies.
- Prices are illustrative USD list prices; annual billing receives roughly 17% savings.
- Primary conversion happens through sales-assisted email links rather than an in-app checkout.
- The artifact is intentionally dependency-free aside from progressively enhanced Google Fonts; fallback fonts preserve usability offline.
