Commercial details

Clear before you commit.

What counts as an operator seat?

Anyone who builds models, changes definitions, or publishes reports is an operator. View-only access is unlimited and free on every plan.

Is implementation included?

Yes. Signal includes two setup sessions, Control includes a four-week guided rollout, and Command includes a named architect and migration plan.

Can we switch plans later?

Yes. Upgrades take effect immediately with a prorated invoice. Downgrades apply at the next renewal, with a 30-day export window for any affected history.

How do you handle security?

Metrik is SOC 2 Type II certified, encrypts data in transit and at rest, and supports configurable retention. Security documentation is available during evaluation.
