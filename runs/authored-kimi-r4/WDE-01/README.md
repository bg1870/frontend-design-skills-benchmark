# Ridgeline marketing site

A responsive, single-page marketing site for a restaurant payroll and scheduling platform.

## Run

Open `index.html` directly, or serve this directory with any static server (for example `python3 -m http.server`).

## Material assumptions

- Ridgeline is positioned for independent U.S. restaurants with scheduling, time tracking, payroll, and a team app.
- Brand, customer names, metrics, testimonials, pricing, and product UI are illustrative marketing content.
- Demo and newsletter forms are front-end interactions only and do not submit to a backend.
- Photography uses externally hosted Unsplash images; internet access is required for imagery and Google Fonts.
