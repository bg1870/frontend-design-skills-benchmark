QUICKSTART•5 MIN READ

Build your first
AI-powered feature.

Install the Nojom SDK, authenticate, and make your first request to Claude—all in a few lines of TypeScript.

Before you begin
Node.js 18+A Nojom API key
01

Install the SDK

Add Nojom to your existing TypeScript or JavaScript project.

Terminal
$ npm install @nojom/sdk
02

Set your API key

Create a key in the Nojom Console ↗, then make it available as an environment variable.

!

Keep your key secret. Never expose it in client-side code or commit it to version control.

.env
NOJOM_API_KEY=nj_live_your_key_here

The SDK reads NOJOM_API_KEY automatically. You can also pass apiKey when creating the client.

03

Make your first request

Create a client and send a message. The response is fully typed.

index.ts
import { Nojom } from "@nojom/sdk";

const nojom = new Nojom();

const response = await nojom.messages.create({
  model: "claude-sonnet-4-20250514",
  maxTokens: 1024,
  messages: [
    { role: "user", content: "Explain quantum computing in one sentence." }
  ]
});

console.log(response.content[0].text);
Run it withnpx tsx index.ts
