TypeScript quickstart

From install to first response.

Use Nojom, our typed wrapper for the Claude API, to send a production-shaped request in a few minutes.

1 Add the package
2 Set your key
3 Call Claude
1

Install Nojom

Add the SDK to an existing Node.js TypeScript project.

Terminal
npm install @nojom/sdk
2

Authenticate

Store your Claude API key in an environment variable. Nojom reads it automatically.

.env
ANTHROPIC_API_KEY=your_api_key_here
Keep keys server-side. Never expose this value in browser bundles or commit .env to source control.
3

Send Your First Request

Create a client and ask Claude for a typed response. The example uses the current Claude Sonnet 4 model ID.

src/index.ts
import { Nojom } from "@nojom/sdk";

const nojom = new Nojom();

const response = await nojom.messages.create({
  model: "claude-sonnet-4-20250514",
  maxTokens: 512,
  messages: [
    { role: "user", content: "Explain our retry policy in 3 bullets." },
  ],
});

console.log(response.text);
$

Estimate Cost Before Shipping

Claude Sonnet 4 usage is billed separately for input and output tokens.

Input tokens$3 / 1M tokens
Output tokens$15 / 1M tokens
Example: 1,000 input + 500 output tokens
(1,000 × $3 + 500 × $15) ÷ 1,000,000 = $0.0105

Pricing shown in USD for Claude Sonnet 4 standard API usage, checked against the public Anthropic pricing available for this model family. Prompt caching, batch processing, and regional pricing can change the total.

Assumptions: Node.js 18+ with ESM and an Anthropic API key; Nojom mirrors the Messages API and returns a normalized response.text.
