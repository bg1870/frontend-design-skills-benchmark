# Ritual — clickable habit tracker prototype

## Run

```bash
npm install
npm run dev
```

## Material assumptions

- The primary user is a busy adult who wants a calm, low-friction daily check-in rather than a data-heavy quantified-self tool.
- The prototype opens on Tuesday, September 8, with local demo data; state resets on refresh.
- Tapping a habit toggles completion. Tapping the streak summary or its arrow opens streak detail. The plus button opens the add-habit sheet; saving adds the new habit to Today.
- Habit frequency is daily in this prototype, and reminders are optional local UI only.
- Visual direction: a compact field-journal layout, cool paper canvas, dark spruce ink, coral action color, and a recurring hand-drawn completion ring. This avoids generic dashboard cards while making today’s list the dominant object.
