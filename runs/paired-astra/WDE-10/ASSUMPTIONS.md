# Material assumptions

- Loomwork is a new brand without an existing visual system; the supplied artifact defines its initial signup direction.
- The primary user is a clinic owner or practice manager creating one workspace for a physiotherapy clinic.
- Signup starts a 14-day trial without payment; account creation is represented locally because no backend or API was supplied.
- Terms, Privacy, login and home destinations remain same-page placeholders pending product routes.
- Schedule data is illustrative and intentionally uses fictional names.
