Quickstart · ~5 minutes

From install to first response.

Nojom is our typed wrapper around the Claude API. Add the package, provide your API key, and ship a working request in three small steps.

Current model claude-sonnet-4-5-20250929
On this page

01

Install the SDK

Add Nojom to your TypeScript project.

Terminal
npm install @nojom/sdk
02

Set your API key

Keep credentials in the environment—never commit them to source.

.env
NOJOM_API_KEY=your_api_key_here

The client reads NOJOM_API_KEY automatically.

03

Send your first request

Create a client and ask Claude for a typed response.

quickstart.ts
import { Nojom } from "@nojom/sdk";

const nojom = new Nojom();

const response = await nojom.messages.create({
  model: "claude-sonnet-4-5-20250929",
  maxTokens: 512,
  messages: [
    { role: "user", content: "Explain this SDK in one sentence." },
  ],
});

console.log(response.content[0].text);

Run it with npx tsx quickstart.ts.

Before you ship

Estimate request cost

Claude Sonnet 4.5 standard API pricing is calculated separately for input and output tokens. Usage is returned with each response.

Input tokens$3 / 1M tokens
Output tokens$15 / 1M tokens
Example: 10K input + 2K output ≈ $0.06
($3 × 0.01) + ($15 × 0.002)
Assumptions: Nojom mirrors the Messages API shape shown above; package name and environment variable follow internal naming conventions. Pricing shown is assumed standard Claude Sonnet 4.5 API pricing, excludes cache/batch discounts and should be checked against your internal billing terms before launch.
