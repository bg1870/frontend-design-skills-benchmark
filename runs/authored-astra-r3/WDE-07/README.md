# Little Hours landing page

A self-contained, responsive landing page in `index.html`.

## Material assumptions

- **Offer:** A downloadable, printable/tablet-friendly planning kit for side projects.
- **Audience:** Independent makers with 2–5 hours a week for personal work.
- **Launch:** “Next month,” per the brief; no invented calendar date.
- **Price:** `$18` is explicitly labeled on-page as an illustrative launch price.
- **Primary conversion:** A local waitlist interaction. No backend or email provider was supplied, so submission validates and confirms in-browser but does not persist addresses.
- **Brand:** Little Hours; paper, moss, coral and pencil-yellow palette; editorial notebook-inspired identity.
- **Contact:** `hello@littlehours.example` is intentionally a placeholder address and must be replaced before launch.

No external fonts, images, libraries, build tooling, or network requests are required. Open `index.html` directly in a browser.
