# Tend — habit tracker prototype

A mobile-first clickable React prototype with a Today checklist, habit streak detail, and add-habit sheet.

## Run

```bash
npm install
npm run dev
```

## Material assumptions

- The experience is a personal, single-user tracker; data is local prototype state and resets on refresh.
- Dates and greeting use the device's current time and locale.
- The Journey tab demonstrates the selected Morning walk habit with sample history; there is no backend or account flow.
- A daily habit is the primary scheduling model, with representative frequency options in the add flow.
