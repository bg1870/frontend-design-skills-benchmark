# Clearpath pricing page

A responsive, dependency-free pricing page for a fictional B2B product analytics company. Open `index.html` directly in a browser.

## Material assumptions

- Clearpath is a fictional product and the plans, limits, and USD prices are illustrative—not verified commercial offers. The page discloses this beside pricing.
- Primary conversion is a sales email; `.example` addresses intentionally avoid implying a live backend.
- Operate is the default annual plan, with a 20% annual discount represented by rounded per-user monthly equivalents.
- Google Fonts are an optional enhancement; system fallbacks preserve the layout offline.
