# Daymark habit prototype

## Material assumptions
- Designed mobile-first for a single person reviewing and completing today's habits.
- The detail screen belongs to “Morning walk,” the highest-streak habit.
- Data is illustrative and remains in memory for the current browser session.
- A newly added habit is scheduled daily and immediately appears in Today.
- Desktop presentation intentionally frames the mobile product rather than inventing a separate desktop IA.

Run with `npm install && npm run dev`.
