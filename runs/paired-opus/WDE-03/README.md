# Meridian Pricing Page

A responsive, accessible static pricing page for a fictional B2B product analytics platform.

## Run

Open `index.html` directly, or serve the folder with:

```sh
python3 -m http.server 8000
```

## Material Assumptions

- Meridian charges only for builders; dashboard viewers are free.
- Team pricing is $18 per builder/month annually or $23 monthly.
- Observe is a free acquisition tier; Control uses annual custom pricing.
- Primary buyers are product and data leaders evaluating governance, query capacity, and security.
- Email links stand in for signup and sales routes because no application backend was provided.
- Google Fonts are loaded from the CDN with local fallbacks.
