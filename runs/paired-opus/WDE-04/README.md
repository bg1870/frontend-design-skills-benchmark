# Ritual — mobile habit tracker prototype

## Run

```bash
npm install
npm run dev
```

## Material assumptions

- Designed for a single mobile user; desktop presents the app in a device-sized canvas.
- Habits are binary daily completions; no accounts, reminders, editing, or persistence in this prototype.
- The initial state uses plausible sample data for Tuesday, September 8, 2026.
- “Streak” means consecutive completed days for the selected habit.
- Visual direction: warm craft. A large, tactile daily progress dial is the signature gesture; quiet paper-like surfaces and Fraunces typography keep routine-building reflective rather than gamified.
