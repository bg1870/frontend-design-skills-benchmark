# Ridgeline marketing page

A responsive, single-file marketing site for Ridgeline. Open `index.html` directly in a browser; no build step or dependencies are required.

## Material assumptions

- Ridgeline is an early-stage payroll and scheduling product for independent US restaurants.
- No verified customer metrics, testimonials, pricing, integrations, or compliance claims were supplied, so the page deliberately avoids inventing them.
- The product UI shown is illustrative and uses plausible sample data rather than representing a live product screen.
- The primary conversion is a guided demo; the placeholder `hello@ridgeline.example` address should be replaced before launch.
- Brand direction was not supplied. The design uses a practical, warm hospitality palette and an editorial voice intended to feel credible to owner-operators.
