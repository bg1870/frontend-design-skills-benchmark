# Material assumptions

- The product is a fictional B2B product analytics platform named **Northstar**; all pricing and limits are illustrative.
- The page is delivered as a dependency-free static website so it can run in any simple web server.
- Annual prices are displayed as monthly equivalents billed yearly; monthly prices are higher and the toggle updates both values and billing copy.
- Trial actions are prototype interactions and show an on-page confirmation rather than connecting to account creation.
- Sales and contact addresses use the reserved `.example` domain and are intentionally non-production.
- Google Fonts are a progressive enhancement; system fallbacks preserve the layout if network access is unavailable.
