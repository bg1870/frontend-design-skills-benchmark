# Ridgeline marketing site

Single-page responsive marketing site for an independent-restaurant payroll and scheduling product.

## Run

Open `index.html` directly, or run `python3 -m http.server 8000` and visit `http://localhost:8000`.

## Material assumptions

- Ridgeline is positioned as a warm, approachable US-focused SaaS brand for independent restaurant owners.
- The primary conversion is a free demo; login and product-detail links are presentational in this static prototype.
- Customer names, metrics, testimonial, rating, and product UI data are illustrative marketing content.
- Photography is loaded from Unsplash and therefore requires network access; all product-interface artwork is native HTML/CSS.
- The delivered artifact uses no framework or build step to maximize portability.
