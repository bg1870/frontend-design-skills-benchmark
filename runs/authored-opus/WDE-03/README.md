# Signalist pricing page

A polished, responsive static pricing page for a fictional B2B product analytics platform.

## Run

Open `index.html` directly, or serve the directory:

```bash
python3 -m http.server 8000
```

## Material assumptions

- Signalist is a fictional B2B product analytics company aimed at product and growth teams.
- Pricing is presented in USD, before tax. Annual pricing is the default and represents the monthly equivalent when paid annually.
- Primary conversion goals are a free trial for self-serve plans and sales contact for Enterprise.
- Customer names/logos are intentionally fictional wordmarks.
- Google Fonts are an optional enhancement; local fallbacks preserve usability if unavailable.
- This is a front-end artifact: CTA destinations and account flows are represented by page anchors and require product integration.
