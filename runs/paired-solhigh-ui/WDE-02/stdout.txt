Built the responsive plumbing dispatcher dashboard using `fixtures/jobs.json`.

### Delivered
- Top summary bar with open, assigned, completed, and next unassigned metrics
- Search and status filtering with URL persistence
- Chronological job queue
- Responsive mobile layout
- Accessible job-details dialog
- Refresh, loading, empty, and error states
- Runtime “As of” timestamp and sample-data labeling
- Material assumptions documented in `ASSUMPTIONS.md`

### Files
- `index.html`
- `styles.css`
- `app.js`
- `README.md`

```bash
python3 -m http.server 8000
```
