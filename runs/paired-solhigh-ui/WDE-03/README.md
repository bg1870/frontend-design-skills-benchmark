# Lattice Analytics pricing page

A self-contained responsive pricing page. Open `index.html` directly in a browser; no build step or dependencies are required.

## Material assumptions

- The product is a fictional B2B product-analytics platform called **Lattice**.
- Pricing is based on monthly tracked events, while seats are unlimited.
- Annual billing saves 20%; listed annual prices are normalized per month and billed yearly.
- `mailto:` CTAs stand in for production signup and sales routes.
- Pricing, allowances, support levels, and contact addresses are illustrative commercial content and should be replaced before launch.
- Privacy and terms links assume production routes at `/privacy` and `/terms`.

## Verification

- Validated that the document parses with Python’s standard HTML parser.
- Checked responsive layout rules at mobile (`≤640px`), tablet (`≤900px`), and desktop widths by static review.
- Audited semantic structure, keyboard focus, touch targets, reduced motion, contrast-oriented tokens, overflow handling, and billing-toggle URL state against the provided Web Interface Guidelines.
