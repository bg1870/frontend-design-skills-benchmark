# Daymark prototype

A clickable mobile habit-tracking prototype with a today view, streak detail, and add-habit sheet.

## Material assumptions
- Designed for an individual building a small, calm daily routine.
- Habit data is local demo state and resets on refresh.
- “Today” and the greeting are derived from the device clock.
- The week display is Monday-first; the streak detail is opened from the reading habit.
- New habits default to daily and can be created from the sheet.

Run with `npm install && npm run dev`.
