Built the plumbing dispatcher dashboard using `fixtures/jobs.json`.

### Files
- `index.html`
- `styles.css`
- `app.js`
- `README.md`

### Included
- Top summary metrics
- Search and status filters
- Technician assignment workflow
- Complete, reopen, and reset actions
- Loading, empty, and error states
- Responsive light/dark interface
- Keyboard shortcut for search
- Documented assumptions in `README.md`

Run with:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
