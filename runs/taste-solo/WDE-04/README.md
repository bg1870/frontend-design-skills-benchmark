# Stride habit prototype

A clickable React prototype with a today view, habit completion, streak detail, and an add-habit sheet.

## Run

```bash
npm install
npm run dev
```

## Material assumptions

- Mobile-first consumer app shown in a device frame on larger screens.
- Sample data is local and resets on refresh.
- Completing habits updates today's progress and the selected habit detail.
- Habits can be scheduled daily, on weekdays, or on selected days.
- The visual system uses one coral accent, cool paper neutrals, 18-24px surfaces, and pill-shaped controls.
- System light and dark modes are supported automatically.
