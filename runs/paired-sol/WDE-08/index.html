Documentation / Quickstart

From Install to First Response.

Add Claude to a TypeScript project with Nojom. You’ll authenticate once, send one request, and know what it costs before you ship.

StartNode.js 18+ and a Nojom API key

FinishA typed Claude response in your console

1. Install2. Authenticate3. RequestCost
1 Install

Add the SDK

Install Nojom in your existing TypeScript project. The package includes its own types.

Terminal
npm install @nojom/sdk
2 Authenticate

Set Your API Key

Keep the key on the server. Nojom reads NOJOM_API_KEY from the environment, so it never needs to enter source control.

.env
NOJOM_API_KEY=your_api_key_here
Do not expose this key in browser code. Call Nojom from a trusted server runtime and add .env to .gitignore.
3 Make a request

Generate Your First Response

Create quickstart.ts. This example uses the current recommended Sonnet model and limits the response to 300 tokens.

quickstart.ts
import { Nojom } from "@nojom/sdk";

const nojom = new Nojom();

const response = await nojom.messages.create({
  model: "claude-sonnet-4-5-20250929",
  maxTokens: 300,
  messages: [
    { role: "user", content: "Explain what an API wrapper does in two sentences." },
  ],
});

console.log(response.content[0].text);
Terminal
npx tsx quickstart.ts
