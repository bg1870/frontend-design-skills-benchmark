# Meridian pricing page

A responsive, standalone pricing page for a fictional B2B analytics product.

## Run

Open `index.html` in a browser, or serve the folder with any static file server.

## Material assumptions

- The product is named **Meridian** and serves product/data teams.
- Usage is measured in monthly tracked events; all plans include the core analytics workspace.
- Explore is free, Team is $149 monthly or $119/month billed annually, and Scale uses custom pricing.
- Trial and sales actions use pre-addressed email links because no application routes or backend were provided.
- Prices are USD, exclusive of applicable taxes.
