## Fix first — blockers

### `fixtures/site/styles.css`

- **Critical — `styles.css:29`** — `:focus { outline: none; }` removes the focus indicator from every interactive element with no replacement. Violates **Focus States: never remove outlines without a visible `:focus-visible` treatment**. Add a ≥2px high-contrast `:focus-visible` outline with offset.

- **High — `styles.css:25`** — Muted text is only **2.45:1** on `--paper` and **2.56:1** on white. WCAG requires **4.5:1 for normal text**. This affects nearly every paragraph, navigation link, icon, and footer line. Darken `--muted`; do not rely on larger type because much of it is 13–16px.

- **High — `styles.css:92`** — Reveal animation has no `prefers-reduced-motion` alternative. Violates **Animation: honor reduced-motion**. Disable opacity/translation transitions in a reduced-motion media query and make content immediately visible.

- **High — `styles.css:95-100`** — Mobile navigation has no real compact state. At 360px, the header has **80px horizontal padding**, plus wordmark, 3 links, gaps, and menu button—well beyond the available width. Violates **Responsive composition: navigation must have a real small-screen state**. Show either links or a functional menu, not both.

### `fixtures/site/index.html`

- **Critical — `index.html:43-61`** — Integration rows navigate through `onclick` on `<li>` elements. They are not keyboard-focusable and provide no keyboard handler. Violates **use `<a>` for navigation** and **interactive elements need keyboard support**. Make each row a real link.

- **Critical — `index.html:19,45,49,53,57,61`** — Six icon-only buttons lack accessible names. Violates **Icon-only buttons need `aria-label`**. The 5 row buttons are also nested inside independently clickable rows and have no distinct behavior; remove them as controls or label and implement them.

- **Critical — `index.html:70`** — Email input has no `<label>` or `aria-label`. Violates **Form controls need labels**. Placeholder text is not a label.

- **High — `index.html:70`** — Email field uses `type="text"` instead of `type="email"` and lacks `autocomplete="email"`. Violates **Forms: correct input type and autocomplete**. Also use `spellcheck="false"`.

- **High — `index.html:19`** — Mobile-menu button has no implemented behavior. **Every visible control must work**; currently activating it does nothing. Add menu state, disclosure semantics (`aria-expanded`, `aria-controls`), and keyboard behavior—or remove it.

## Fix second — serious usability defects

### `fixtures/site/styles.css`

- **High — `styles.css:70`** — Icon targets are approximately **36×36px** for the 20px menu icon and **32×32px** for 16px row icons. The minimum touch target is **44×44px**. Increase the interactive area.

- **High — `styles.css:98`** — Mobile `.btn` height is approximately **31px**: 13px × 1.6 line-height + 8px vertical padding + 2px border. This misses the **44×44px touch-target minimum**.

- **High — `styles.css:40,84`** — Only `.btn` has a hover state; navigation, integration rows, icon buttons, and footer link do not. Violates **Hover & Interactive States: links/buttons need visible hover feedback**. Ensure hover/active states increase contrast.

- **Medium — `styles.css:40,62,90,98-99`** — UI and content text drops to **12–13px** in navigation, summary, footer, and mobile buttons. Guidance sets **12–14px only for clear labels with sufficient contrast** and discourages body copy below 16px on small screens. The 2.45:1 muted color makes this substantially worse.

- **Medium — `styles.css:43`** — Mobile content gutters remain **40px**, leaving only 280px at a 360px viewport. Recommended mobile gutters are roughly **16–24px**. This unnecessarily compresses the form, hero, and navigation.

- **Medium — `styles.css:47-55`** — Headings have no `text-wrap: balance`/`pretty`, increasing widows and awkward mobile wrapping. Violates **Typography: balance headings**.

- **Medium — `styles.css:31-36`** — Header is not sticky, but anchor targets still have no `scroll-margin-top`. The guideline requires `scroll-margin-top` on heading/section anchors for robust in-page navigation.

### `fixtures/site/index.html`

- **High — `index.html:17,26`** — Duplicate `id="cta"` values make the document invalid and DOM targeting ambiguous. IDs must be unique. Remove the IDs or assign distinct ones.

- **High — `index.html:12-22`** — No skip link before navigation. Violates **Accessibility: include a skip link for main content**. Add a keyboard-visible “Skip to main content” link and an ID on `<main>`.

- **High — `index.html:44-60`** — All integration images omit explicit HTML `width` and `height`. CSS sizing does not reserve intrinsic layout before styles arrive. Violates **Images: explicit dimensions prevent CLS**. Add `width="24" height="24"`.

- **Medium — `index.html:44-60`** — Below-fold integration logos do not use `loading="lazy"`. Violates **Images: lazy-load below-fold imagery**.

- **Medium — `index.html:27`** — The above-fold hero image lacks `fetchpriority="high"`. Guideline: mark critical above-fold imagery as high priority.

- **Medium — `index.html:19,45,49,53,57,61`** — SVG icons are unnamed visual decoration inside their controls. Once controls receive text labels, add `aria-hidden="true"` to the SVGs. Violates **Decorative icons need assistive-technology hiding**.

- **Medium — `index.html:34`** — Straight apostrophe in `shift's`; typography rule specifies curly punctuation (`shift’s`).

- **Low — `index.html:7-8`** — Google Fonts preconnect covers `fonts.googleapis.com` but not the actual font asset origin, `fonts.gstatic.com`. Add a cross-origin preconnect to reduce connection setup time.

## Fix third — design quality and consistency

### `fixtures/site/styles.css`

- **Medium — `styles.css:38,48,62`** — Four font families are loaded and used: Inter, Playfair Display, Roboto Mono, and Lobster. The design guidance recommends **at most 2 families and 3 weights**. The script wordmark, editorial serif, monospace label, and neutral sans create competing identities rather than a coherent veterinary-workflow voice.

- **Medium — `styles.css:59-60`** — “How it works” defaults to 3 identical bordered, rounded cards. The cards are neither independently actionable nor movable; guidance says **do not tile every supporting paragraph into floating cards**. This weakens hierarchy, though it is not a usability blocker.

- **Medium — `styles.css:62`** — The summary uses the common generated-page treatment of **uppercase tracked monospace metadata**. It does not encode a technical value or sequence and is harder to read at 13px.

- **Low — `styles.css:49,97`** — Hero type jumps from 52px to 32px at one breakpoint rather than scaling fluidly. Guidance recommends `clamp()` for display sizes to avoid abrupt composition changes.

- **Low — `styles.css:92`** — Every major section receives the same fade-and-slide reveal. The design rule advises one deliberate motion moment rather than repeated generic section entrances.

### `fixtures/site/index.html`

- **Medium — `index.html:41`** — “Connects to 12 practice management systems” is followed by only 5 systems, with no route to view the remaining 7. The claim and displayed evidence do not align. Clarify “including” or provide access to the full list.

- **Low — `index.html:13`** — The wordmark is a non-linked `<span>`. Common navigation expectation is that the brand returns to the homepage; use a home link if this is not already the home-only experience.

## Recommended order

1. Restore visible focus and replace clickable `<li>` rows with links.
2. Label and implement/remove every icon button; label and correct the email field.
3. Fix muted-text contrast to ≥4.5:1.
4. Build a non-overflowing, functional mobile navigation and restore ≥44px targets.
5. Honor reduced motion.
6. Add skip navigation, unique IDs, image dimensions/lazy loading, and anchor scroll margins.
7. Then address typography, card repetition, motion repetition, and the incomplete integrations claim.
