# Material assumptions

- **Product:** Meridian is a fictional B2B analytics workspace used only to give the page a coherent product context.
- **Commercial terms:** No pricing, limits, discounts, customer evidence, security certifications, SLAs, or contract promises were supplied. The page therefore labels the plan structure as illustrative, uses “Custom,” and routes users to a sales conversation rather than implying checkout.
- **Plan structure:** Explore, Operate, and Govern—and all listed capabilities—are illustrative information architecture, not live product commitments.
- **Contact:** `sales@example.com` is a placeholder mail destination and must be replaced before production.
- **Implementation:** The deliverable is a dependency-free static site (`index.html`, `styles.css`, `script.js`) intended to work from a file server or direct file open. Google Fonts are an enhancement; system sans-serif fallbacks remain available if offline.
