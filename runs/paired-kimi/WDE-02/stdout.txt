Built the plumbing dispatcher dashboard.

### Files
- `index.html` — responsive dashboard with summary metrics, searchable/filterable job queue, accessibility states, and URL-synced filters.
- `README.md` — run instructions and documented assumptions.
- `fixtures/jobs.json` — used dynamically as the data source.

### Run
```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

Validated HTML/JavaScript syntax, JSON loading, and static server delivery.
