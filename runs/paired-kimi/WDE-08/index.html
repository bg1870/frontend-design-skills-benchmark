From Install to Response.

1

Install the Package

Use Node.js 20 or later. Nojom ships with its own TypeScript declarations.

shell
npm install @nojom/sdk
2

Authenticate Locally

Create an API key in the Anthropic Console, then expose it to Nojom through your environment. Never commit this value.

.env.local
ANTHROPIC_API_KEY=sk-ant-…
3

Send Your First Request

Create a client and call messages.create. The SDK reads your key automatically and keeps the response fully typed.

src/hello.ts
import { Nojom } from "@nojom/sdk";

const nojom = new Nojom();

const message = await nojom.messages.create({
  model: "claude-sonnet-4-5-20250929",
  max_tokens: 256,
  messages: [
    { role: "user", content: "Name one moon of Saturn." }
  ]
});

console.log(message.content[0].text);
responseTitan is one of Saturn's moons.742 ms
Before you ship

Know the Cost of Every Call.

Claude Sonnet 4.5 is billed by tokens processed. Nojom adds no usage markup. Cache and batch discounts are not included in this quick estimate.

Input$3.00per 1M tokens
Output$15.00per 1M tokens

Example request1,000 input + 250 output tokens
